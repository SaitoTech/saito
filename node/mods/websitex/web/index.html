How Saito works

Useful traffic should sustain useful infrastructure.

Saito aligns applications, users, and the nodes carrying their data—so an open network can support real browser applications.

BYour browserCreates useful traffic
PRouting peerCarries the data
PRouting peerConnects the edge
ASaito appReaches another peer
  1. 01

    Applications create value

    Messages, moves, posts, calls, and offers begin in the browser.

  2. 02

    Peers carry the traffic

    Independent infrastructure connects applications and their users.

  3. 03

    The network rewards routing

    Consensus directs value toward infrastructure that serves the network.

  4. 04

    The edge stays open

    Developers build applications instead of rebuilding a closed platform.

Build on Saito

Build an app, not another platform.

Saito modules are browser-native applications with access to shared network, wallet, identity, peer-service, and transaction capabilities.

Start building ↗ Explore modules ↗

mods/hello/hello.js

class Hello extends ModTemplate {
  constructor(app) {
    super(app);
    this.name = 'Hello';
  }

  async onPeerHandshakeComplete(app, peer) {
    this.render(app);
  }
}

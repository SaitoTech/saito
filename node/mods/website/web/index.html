How Saito works

            
Useful traffic should sustain useful infrastructure.

          

          

            

              Saito aligns applications, users, and the nodes carrying their data. Applications pay
              nodes directly for the infrastructure they need. No middlemen to extract, control, or
              censor.

Everything works together

            
Publish here. Discover there. Use it everywhere.

            

              Users can use their identity, assets, and data across any application on the network.
            

            

              

                Different Apps
Same Data
                

                  A game invite can be a tweet. A store lisitng can be a post in your feed. A chat
                  message can be a game move.
                

              

              

                Same Data
Different Apps
                

                  Developers compete to build apps the best experience. Users can choose between
                  different apps to access the same conetnt.
                

              

              

                Your Data
Always
                

                  Identity, contacts and data belong to the user not the platform. There's not
                  penalty to switch apps.

Build on Saito

            
Build an app, not another platform.

            

              Saito modules are browser-native applications with access to shared network, wallet,
              identity, peer-service, and transaction capabilities.
            

            

              
                Start building ↗
              
            

          


          

            

              

              
mods/hello/hello.js

              
            

            
class Hello extends ModTemplate {
  constructor(app) {
    super(app);
    this.name = 'Hello';
  }

  async onPeerHandshakeComplete(app, peer) {
    this.render(app);
  }
}

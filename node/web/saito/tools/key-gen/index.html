    Before you trust it

    Cold-storage checklist

    1
    Verify the file

    Obtain index.html from a trusted release and compare its published SHA-256 digest.

    2
    Use a clean device

    Open the file in an up-to-date browser without extensions, ideally on a dedicated computer.

    3
    Disconnect physically

    Turn off Wi-Fi and Bluetooth and remove network cables before generating or restoring keys.

    4
    Back up offline

    Write, print, or download the secrets, verify the copy, then clear the utility and shut down the device.
